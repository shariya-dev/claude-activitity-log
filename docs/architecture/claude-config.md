## 3. File map — where each instruction lives (one home per rule)

```
/CLAUDE.md                              Project map, PRD invariants (8 bullets), workflow pointer, commands. Always loaded. ≤ 120 lines.
/.claude/settings.json                  Shared permissions (allow test/lint/build cmds; deny .env reads, git push, force ops). Committed.
/.claude/settings.local.json            Personal overrides. Git-ignored.
/.claude/rules/sync-protocol.md         paths: agent sync/contract + backend Ingestion/Agent API. Cursor/idempotency/error rules.
/.claude/rules/privacy.md               paths: agent claude/detect/sync + backend Ingestion, SessionMessage, prompts UI. Tracking-category & prompt rules.
/.mcp.json                              laravel-boost MCP (`php agent-dashboard/artisan boost:mcp`). Committed.
/6am-agent/CLAUDE.md                    Agent-only conventions, commands, module boundaries. Loaded when working in 6am-agent/.
/agent-dashboard/CLAUDE.md              GENERATED by Boost (do not edit). Includes .ai/guidelines/*.
/agent-dashboard/.ai/guidelines/6am-backend.md   Backend project conventions (source for Boost). Staged at docs/claude-config/ until H01 moves it.
/agent-dashboard/.claude/skills/*       GENERATED by Boost (if Boost version ships skills). Do not edit.
/docs/architecture/*.md                 Design source of truth (read on demand; not auto-loaded).
/docs/contracts/*.md                    Verified data contract (H02) + sync API contract (H03).
/docs/handovers/PROTOCOL.md             How every handover is executed, reviewed, committed.
/docs/handovers/HNN-*.md                One handover per implementation unit.
~/.claude/…                             Untouched. Superpowers stays global.
```

Rules of placement:
- A rule appears in exactly one file. Root `CLAUDE.md` holds only cross-cutting invariants; component rules go to the component file; path-scoped rules go to `.claude/rules/` with `paths:` frontmatter (loaded only when matching files are touched).
- Architecture explanations are **referenced** from CLAUDE.md, never pasted into it.
- Handover docs may restate a rule only as a checklist item pointing to its home.
- Boost-generated files are regenerated with `php artisan boost:update`, never edited.
- If the installed Claude Code version does not load nested `agent-dashboard/.claude/skills`, backend agents should start Claude from `agent-dashboard/` or invoke skills by path; do not copy them to the root.
