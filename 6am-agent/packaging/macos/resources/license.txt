What it does: the agent runs in the background as the signed-in user and sends Claude Code
usage metadata (sessions, projects, models and token counts) to the company monitoring
dashboard. Prompt text, Git details and network details are sent only when an administrator
turns those categories on centrally. The agent only reads Claude Code's data folder and never
changes it.

Uninstall: sudo "/Library/Application Support/6amAgent/current/uninstall.sh"
