# Claude Code Activity Monitor (6AM Technologies)

Internal system: a cross-platform desktop **agent** reads Claude Code's local data and syncs usage to a **Laravel + Inertia/Vue** dashboard.
Requirements: `PRD.md`. Design: `docs/architecture/`. Contracts: `docs/contracts/`. Work units: `docs/handovers/`.

## Layout
- `6am-agent/` — Node 24 + TypeScript agent (see `6am-agent/CLAUDE.md`)
- `agent-dashboard/` — Laravel app: agent API (`/api/agent/v1`) + dashboard (see `agent-dashboard/CLAUDE.md`, generated by Laravel Boost)
- `tools/claude-data-probe/` — Phase 0 probe script
- `docs/` — architecture, contracts, handovers

## Non-negotiable invariants (PRD)
1. Token math lives only in the backend (`App\Support\TokenMath`): actual = input + output + cache_creation; total = actual + cache_read. Never label it billing, cost, or quota.
2. Agent checkpoints/cursor advance only after a `200` sync response with `success: true`.
3. Prompt tracking OFF ⇒ no prompt text read into payloads, sent, or stored. Default OFF. Git and Network default OFF.
4. No queue infrastructure (Redis/RabbitMQ/Kafka/SQS/queue workers). `QUEUE_CONNECTION=sync`.
5. Network data never identifies a developer or device.
6. OS-specific agent code only in `6am-agent/src/platform/<os>/`. Backend schema is platform-neutral.
7. Disabling/uninstalling a device never deletes history (`restrictOnDelete`, status columns).
8. Agent reads only Claude's data dir, `~/.claude.json` (oauthAccount), and `.git/config|HEAD` only when Git tracking is ON. Never writes there.

## Workflow
- Every change is a handover: follow `docs/handovers/PROTOCOL.md` and the specific `docs/handovers/HNN-*.md`.
- Stay inside the handover's **Owned files**. Need something outside? Stop and report it; don't edit it.
- Use Superpowers skills (installed globally): TDD, verification-before-completion, requesting-code-review.
- Do not add dependencies outside the handover's allowance. Do not `git push`.
